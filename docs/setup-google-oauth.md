# 구글 드라이브 백업 설정하기

앱이 구글 드라이브에 백업하려면 **본인 소유의 OAuth 클라이언트**가 필요해요. 한 번만 하면 돼요.

## 1. Google Cloud 프로젝트 만들기
1. <https://console.cloud.google.com/> 에 로그인합니다.
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름(예: `workout-app`) → 만들기.

## 2. Google Drive API 켜기
1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**.
2. "Google Drive API" 검색 → **사용**.

## 3. OAuth 동의 화면
1. **API 및 서비스 → OAuth 동의 화면**(Google 인증 플랫폼).
2. 사용자 유형 **외부**, 앱 이름(예: 운동 기록), 지원 이메일·개발자 연락처에 본인 이메일.
3. 범위(Data access)에 `.../auth/drive.file` 하나만 추가합니다. 앱이 만든 파일만 볼 수 있는 범위예요.
4. 테스트 사용자에 본인 구글 계정을 추가합니다.

> **7일마다 다시 로그인해야 하는 문제:** 게시 상태가 **테스트**이면 구글이 리프레시 토큰을 7일 뒤 만료시켜요.
> `drive.file`은 구글 문서에서 **민감하지 않은 범위**로 분류되어 있으므로, 동의 화면의 게시 상태를
> **프로덕션으로 게시**하면 이 7일 만료가 없어집니다. (게시할 때 구글이 추가 확인을 요구하면 화면 안내를 따르세요.)

## 4. 클라이언트 ID 만들기
1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**.
2. 애플리케이션 유형 **데스크톱 앱**, 이름 아무거나 → 만들기.
3. 나오는 **클라이언트 ID**와 **클라이언트 보안 비밀번호(secret)** 를 복사합니다.

## 5. 앱에 넣기
1. 앱 대시보드 → **설정 → 구글 드라이브 백업**.
2. 클라이언트 ID·secret 붙여넣기 → **클라이언트 저장**.
3. **구글로 로그인** → 열린 브라우저에서 직접 로그인·허용 → "로그인 완료" 창이 뜨면 앱으로 돌아옵니다.
4. **지금 백업**. 이후에는 앱이 켜져 있는 동안 10분마다 바뀐 것이 있으면, 그리고 하루에 한 번 자동으로 백업해요.

## 알아 두기
- 백업은 `내 드라이브/WorkoutApp/` 아래에 `files/날짜/…`와 `library.db`로 올라가요. 로컬과 드라이브 어느 쪽 파일도 지우지 않아요.
- 로그인 토큰은 이 컴퓨터의 키 보관함(macOS 키체인, Windows 자격 증명 관리자, Linux Secret Service)에만 저장돼요.
- **클라이언트 ID·secret을 꼭 보관하세요.** 이 앱은 `drive.file` 권한만 쓰기 때문에, 같은 Cloud 프로젝트의 같은
  클라이언트로 로그인해야 예전 백업(WorkoutApp 폴더)이 보여요. 다른 클라이언트로 로그인하면 복원할 백업을 찾지 못해요.
- 새 PC에서는 앱을 설치하고 같은 클라이언트로 로그인한 뒤, 라이브러리가 비어 있을 때 **드라이브에서 복원**을 누르세요.
  비어 있는 라이브러리는 자동 백업하지 않으므로 복원 전에 빈 내용이 올라가지 않아요.
- 한 드라이브 백업은 한 라이브러리만 씁니다. 다른 PC에서 따로 운동을 가져온 라이브러리로 로그인하면, 기존 백업을
  덮어쓰지 않고 "다른 PC의 백업이 있어요"라고 멈춰요. 두 PC를 동시에 쓰는 것은 지원하지 않아요.
